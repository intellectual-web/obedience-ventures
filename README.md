# OBEDIENCE VENTURES website

Website slogan: **TESTED AND TRUSTED**

## Files
- `index.html` — website content
- `style.css` — styling and mobile layout
- `assets/obedience-ventures-logo.png` — logo

## Publish with GitHub Pages
1. Create a public repository, for example `obedience-ventures`.
2. Upload `index.html`, `style.css`, and the complete `assets` folder. Do not upload only this ZIP file.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site and open the published link.
